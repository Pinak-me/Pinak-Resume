# Pinak — Resume Website

A responsive, static resume website built with HTML and CSS. Resume content is present as readable HTML text.

## Preview locally
Open `index.html` in a web browser.

## Publish for free with GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a **public** repository (for example, `pinak-resume`).
3. Upload `index.html` to the root of the repository and commit the changes.
4. Open the repository's **Settings → Pages**.
5. Under build/deployment, select **Deploy from a branch**.
6. Select branch `main` and folder `/(root)`, then save.
7. Wait for GitHub Pages to publish the site. The URL will appear on the Pages settings screen.

## Verify the assignment requirement
Open the published URL, press `Ctrl+U`, then use `Ctrl+F` to search for:
- `Hello, I'm Pinak`
- `Education`
- `Financial Accounting`
- `Eiffel Landmark`

The website's text should be present in the page source. This is a useful technical check, but it does not guarantee that every AI tool will index or recommend the site.

## Before publishing
Check every resume detail for accuracy. Add no dates, responsibilities, achievements, or credentials unless you can verify them.
